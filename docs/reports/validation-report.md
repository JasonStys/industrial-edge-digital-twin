## Browser scenarios

- Live schema-validated telemetry and axe scan.
- In-memory token use and operating-mode change.
- Frozen sensor → stale quality → faulted controller → safe requested outputs.
- Pump stuck-on → requested/actual mismatch.
- Keyboard skip-link focus transfer.
- No horizontal document overflow at desktop and Pixel 7 viewports.

The first concurrent browser run revealed a shared-state race between desktop and mobile projects.
The suite now uses one worker because both projects intentionally control the same twin instance.
This is a test-architecture correction, not a retry policy.

## Known evidence limits

- Automated browser checks do not replace manual screen-reader/user testing.
- Local MSVC does not provide the Linux sanitizer evidence; CI performs that gate after push.
- MQTT tests use a deterministic adapter double. A live local broker remains an optional manual
  integration exercise.
- The benchmark includes simulation and JSON serialization but discards output before disk I/O.
